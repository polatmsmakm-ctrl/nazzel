# تحضير (Tahdeer)

تطبيق آيفون: ترفع فيديو شرائح الدرس، ويكتب لك تحضير الدرس على ورقة مسطّرة بخط اليد. بعدها تقدر تعدّله وتحفظه صورة أو PDF.

- يشتغل مجاناً بمفتاح Gemini تطلعه من aistudio.google.com/apikey، أو بمفتاح Claude API المدفوع. المفتاح تحطه في إعدادات التطبيق.
- آخر نسخة IPA موجودة في صفحة Releases (الإصدارات اللي تبدأ بـ `tahdeer-`). ثبّتها عن طريق Sideloadly.
